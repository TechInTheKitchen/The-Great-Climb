# Climber Card

Copy onto a 3 × 5-inch card; keep the words short.

```text
NAME __________________  WEEKS ON ASTER ____
HOME ______________________________________
WHY THE SUMMIT? ___________________________
IRREPLACEABLE OBJECT ______________________

TRAINED (circle one; use once per leg)
STRENGTH: grip, haul, brace, carry
COURAGE: exposed or frightening action
WILLPOWER: cold, fatigue, long effort
USED THIS LEG [ ]     EXPOSURE [ ] [ ] [ ]

BODY CHANGE / WHAT NOW FEELS ORDINARY:
__________________________________________

BACK: Draw the rope team. Write a promise
between each pair of neighboring climbers.
```

On a check, the leader names the danger and how their trained skill meets it. If it fits, flip **one fewer tile** (minimum one) and mark USED. The team shares a separate Rope Strain track. See [[The Ascent]].
